# B-27 Home情報密度・並び替え仕様

Status: Accepted v0.1
Decision ID: B-27

## 1. 目的

Homeは「薄いリンク集」ではなく、詳細画面を開かなくてもその日のマネジメント判断がかなりできる濃さを持つコクピットとして扱う。

## 2. 上段4カードの情報密度

対象カード:
- 自分が動く
- 手放す
- 褒める
- 詰まりを取る

PCでは4カードを横並びとし、カード高さは固定する。

各カードは視認性を優先し、通常表示では上位3件まで表示する。

基本表示要素:
- カード名
- 総件数
- 上位3件
- 各項目の短い理由または補助シグナル
- 4件目以降がある場合は `ほかN件` を表示

4件目以降や詳細はカード押下後のCentered Modalで確認する。

## 3. 並び替え

Home上段4カードは共通の並び替え基準を持つ。

並び替え候補:
1. 優先度
2. 期限
3. 影響度

デフォルトは `優先度` とする。

原則:
- カードごとに個別の並び替え状態は持たせない。
- Home上段に共通の並び替えUIを1つ置く。
- 選択した基準を4カードすべてに同時適用する。
- 並び替え基準を変えても各カードの表示件数は上位3件のまま維持する。

## 4. 表示上の優先事項

- カード間比較をしやすくするため、高さを揃える。
- 情報量を増やしても、1件あたりの説明は短く保つ。
- Homeで全文や長い根拠を表示しない。
- 詳細根拠・履歴・編集はCentered Modalまたは詳細画面へ分離する。
- Homeの役割は「一瞬で優先順位を把握し、次の判断へ進むこと」とする。
