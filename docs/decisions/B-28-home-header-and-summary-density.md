# B-28 Home上部・情報密度仕様

Status: Accepted v0.1
Decision ID: B-28

## 1. 目的

Homeはプレイングマネージャーの判断コクピットとして、詳細画面を開かなくても当日の判断がかなりできる情報密度を持たせる。

## 2. Home上部

Home最上部には次を配置する。

- 日付
- 今日のモード
- Home上段4カード共通の並び替え
- Decision Pack状態

### 今日のモード

AI返却の `management_focus_type` / `management_focus_summary` を短く表示する。

目的:
- 今日が「プレイヤー優先」「チームフォロー優先」「委譲優先」「ボトルネック解消優先」「仕組み化優先」など、どの運転モードかをHomeに入った瞬間に把握できるようにする。
- 手動で変更せず、AI判断の記録として扱う。

## 3. 上段4カードの密度

対象:
- 自分が動く
- 手放す
- 褒める
- 詰まりを取る

表示ルール:
- 4カードは高さ固定。
- 各カードは上位3件まで表示。
- 4件目以降は `ほかN件` でまとめる。
- 各項目は `タイトル + そのカード特有の判断材料2つ` に統一する。

カード別の判断材料:

### 自分が動く
- 期限・緊急度
- 次の一手

### 手放す
- 手放せる理由
- 現在の委譲レベル

### 褒める
- 良かった事実
- 根拠

### 詰まりを取る
- 停滞期間・状態
- 原因シグナル

## 4. 上段4カードの並び替え

Home上段4カードは共通の並び替えコントロールを持つ。

候補:
- 優先度
- 期限
- 影響度

デフォルト:
- 優先度

原則:
- カードごとに個別の並び替え設定は持たない。
- Home上部の1つの切替で4カードすべてに同じ基準を適用する。
- 比較しやすさと視認性を優先する。

## 5. 下段3ブロックのHome内表示

### 当日のスケジュール

Homeでは当日分のみ表示する。

表示項目:
- 次の予定
- 今日の残り予定
- 空き時間

詳細を見たい場合はカレンダーページへ遷移する。

### 今月の進捗 + AIコメント

Home内で完結し、押下による別ページ遷移は必須としない。

表示項目:
- 自分KPI
- チームKPI
- 残り営業日
- 今日の配分判断につながるAIコメント

AIコメントは単なる数値要約ではなく、例えば「今日は自分で数字を作るよりチームフォローを優先」など、プレイングマネージャーの当日配分判断につながる短い示唆とする。

### チーム状態

Homeでは次の事実を要約表示する。

- 負荷が偏っているメンバー
- 停滞・期限超過件数
- 1on1が空いているメンバー
- 要フォロー / 褒める / 手放す候補件数

AIによる人物評価は行わず、事実ベースで表示する。

## 6. Home全体の情報設計

```text
Home上部
  日付 / 今日のモード / 並び替え / Decision Pack状態

上段
  今日どう動くか
  自分が動く / 手放す / 褒める / 詰まりを取る

下段
  判断の前提となる現在地
  当日のスケジュール / 今月の進捗 + AIコメント / チーム状態
```

Homeは薄いランチャーではなく、当日のマネジメント判断をかなりHome内で完結できる濃いコクピットとして設計する。
